# Zorile Mării

Site de prezentare pentru restaurantul Zorile Mării din Constanța.

- `index.html` — pagina publicată pe GitHub Pages (React, Tailwind și Framer Motion încărcate din CDN).
- `images/` — fotografiile folosite (Unsplash, provizorii până la pozele reale ale restaurantului).
- `src/ZorileMarii.jsx` — componenta sursă.
